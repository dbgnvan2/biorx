        Getting a DeepSeek API key
        1. Go to platform.deepseek.com and sign up or sign in.
        2. Add money to your balance (the Top up page). Usage is taken from your balance; any free credit DeepSeek has granted your account is used first.
        3. Open API keys, click Create new API key, and copy it — DeepSeek shows it only once.
        4. Here: set Provider to deepseek, paste the key into Your API key, leave Model blank (the default is deepseek-flash), and click Save.

        Cost: a summary on deepseek-flash is roughly $0.002 (about 500 summaries per dollar). With your own key there is no daily limit; you pay DeepSeek directly.

        Your key is kept in this browser, and stored encrypted on the server only if the server has encryption set up. Remove it any time with Remove key.

        Default sources

        Sources ticked here start out ticked in the Search tab and in new filters. You can still change them for any single search. Saved in this browser only.

        Full text for summaries

        Before summarizing, BioRx looks for a free copy of the paper: its own link, then Unpaywall, OpenAlex and Semantic Scholar. With no full text found, the abstract is kept and no model is used. Saved in this browser only.
